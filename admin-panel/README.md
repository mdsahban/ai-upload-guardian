# AI Upload Guardian — Admin Panel (React + Node + FastAPI)

This folder contains the **admin dashboard** and **backend services** for reviewing upload requests generated by the browser extension.

**First-time setup:** from the repository root run `scripts\setup.ps1`, then `scripts\start-admin.ps1`. See the root **`README.md`** for the full picture (both `extension` and `extension-user`).

- `fastapi/` — FastAPI REST API + SQLite persistence  
- `node/` — Node/Express gateway (proxy + place for realtime later)

## API contract (MVP)

- `POST /v1/requests` — create a new review request
- `GET /v1/requests` — list requests
- `GET /v1/requests/{id}` — request detail
- `POST /v1/requests/{id}/decision` — approve / block (+ optional reason)

The React dashboard talks to the **Node gateway** (`http://localhost:8080/api/...`), which proxies to FastAPI.
